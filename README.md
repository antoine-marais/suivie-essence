# Fuel Log

PWA de suivi auto : pleins, autres dépenses, budget, km et consommation. FR/EN, thème sombre, hors ligne, plusieurs véhicules.

- **Données** : stockées sur l'appareil (localStorage). Export/import JSON, export CSV.
- **Synchro téléphone + PC** (optionnelle) : Supabase gratuit. Exécuter `supabase.sql`, puis renseigner l'URL, la clé anon et une clé de synchro dans Réglages. Le SQL est aussi copiable depuis l'appli.
- **Sauvegarde automatique** dans un fichier : Chrome / Edge sur PC.
- **Prix autour de moi** : données ouvertes data.gouv.fr (France).
